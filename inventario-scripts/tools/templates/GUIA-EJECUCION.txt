Los scripts inventarioMac e inventarioLinux detectan el hardware
del equipo y abren el navegador con el formulario CMDB precargado.


--- REQUISITOS ------------------------------------------------

  - Conexion a internet
  - Terminal con bash
  - Navegador web instalado (Chrome, Firefox, etc.)


--- LINUX -----------------------------------------------------

  1. Abrir terminal (Ctrl + Alt + T)

  2. Ir a la carpeta del script:
     cd /ruta/a/Mac\ y\ Linux/

  3. Dar permisos (solo la primera vez):
     chmod +x inventarioLinux

  4. Ejecutar:
     bash inventarioLinux

  5. Escanear o escribir la placa cuando lo solicite.


--- macOS -----------------------------------------------------

  1. Abrir Terminal (Spotlight: Cmd + Espacio, escribir "Terminal")

  2. Ir a la carpeta del script:
     cd /ruta/a/Mac\ y\ Linux/

  3. Dar permisos (solo la primera vez):
     chmod +x inventarioMac

  4. Ejecutar:
     bash inventarioMac

  5. Escanear o escribir la placa cuando lo solicite.


--- SOLUCION DE PROBLEMAS -------------------------------------

  Permission denied
    -> Ejecutar el paso chmod +x antes de correr el script.

  Command not found
    -> Verificar que estas en la carpeta correcta (paso cd).

  No abre el navegador
    -> Comprobar conexion a internet. El script mostrara la URL
       para abrirla manualmente.

  Datos incompletos en el formulario
    -> Completar los campos faltantes en la pagina y guardar.
